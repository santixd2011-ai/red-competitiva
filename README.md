# Red Competitiva

Utilidad de Windows en Python para optimizar y ajustar la configuración de red, pensada para entornos competitivos.

## Uso

Ejecuta `Red_Competitiva.pyw` con doble clic. La herramienta puede exportar una copia de seguridad de los perfiles inalámbricos antes de aplicar cambios.

## Requisitos

- Python 3.x en Windows
- Permisos de administrador para algunas operaciones

## Aviso

Esta herramienta modifica ajustes de red del sistema. Revisa el código antes de ejecutarla y conserva siempre la copia de seguridad de tus perfiles.
